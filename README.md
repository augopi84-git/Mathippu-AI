# Mathippu-AI (மதிப்பு = Value AI)

Global Equity Market Valuation Radar & Research Index.

> **Mathippu** (மதிப்பு) is the Tamil word for **Value / Valuation**.

## Features
- **Global Valuation Heatmap & Matrix**: Multi-factor scoring across 32+ global economies.
- **Real-Time Data Sync & Timestamp Protocols**: Ingests Yale Shiller CAPE data, IMF Macro indicators, Yahoo Finance live closing feeds, and AI quantitative models.
- **Historical Month-Wise & Year-Wise Valuation Trends**: Detailed stacked distribution charts (Undervalued, Fairly Valued, Overvalued, Bubble) and benchmark index trajectories.
- **Interactive Multi-Factor Sliders**: Customize weights for CAPE, Trailing P/E, Forward P/E, P/B, Buffett Indicator, and Dividend Yield.
- **AI Quantitative Research**: Deep investment theses, scenario shock impacts, and return forecasts for each market.
